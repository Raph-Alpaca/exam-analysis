# 성취평가 결과 분석 (exam-analysis)

NEIS에서 내려받은 **교과목별 학생답 정오표**와 **문항정보표**를 수정 없이 그대로 올리면
성취평가(성취수준 A~E) 결과 분석이 바로 나오는 웹 도구입니다.

- 사이트: https://raph-alpaca.github.io/exam-analysis/
- 모든 처리는 **브라우저 안에서만** 이루어집니다. 파일과 학생 정보는 어떤 서버로도 전송되지 않습니다.
- 설치가 필요 없고, 엑셀 파일을 끌어다 놓기만 하면 됩니다.

## 올릴 수 있는 파일

| 파일 | 필수 | NEIS 메뉴 |
|---|---|---|
| 교과목별 학생답 정오표 (반별) | 필수 | 성적 › 지필평가조회 › 교과목별 학생답 정오표 조회 › 저장 |
| 문항정보표 (성취기준·난이도 포함) | 선택 | 성적 › 지필평가 › 문항정보표 › 출력 › XLS data |
| 정답/배점표 | 선택 | 성적 › 지필평가조회 › 정답/배점 |
| 문항분석표 | 선택 | 성적 › 지필평가조회 › 문항분석표 (학년 전체 비교에 사용) |

정오표만 있어도 성취도·문항·성취수준별 분석이 모두 됩니다. 문항정보표를 함께 올리면 성취기준·내용영역별 분석이 추가됩니다.

## 개발

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest
npm run build      # dist/
```

실제 NEIS 샘플로 검증하려면 샘플 폴더 경로를 환경변수로 지정합니다 (샘플은 저장소에 포함하지 않습니다).

```powershell
$env:NEIS_SAMPLE_DIR = "C:\경로\성취평가"
npm test -- --run
```
