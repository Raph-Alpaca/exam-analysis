# 성취평가 결과 분석 (exam-analysis)

NEIS에서 내려받은 **교과목별 학생답 정오표**와 **문항정보표**를 **수정 없이 그대로** 올리면
성취평가(성취수준 A~E) 결과 분석이 바로 나오는 웹 도구입니다.

- 사이트: **https://raph-alpaca.github.io/exam-analysis/**
- 모든 처리는 **브라우저 안에서만** 이루어집니다. 파일과 학생 정보는 어떤 서버로도 전송되지 않고, 새로고침하면 사라집니다.
- 설치가 필요 없습니다. 엑셀 파일을 끌어다 놓기만 하면 됩니다. "예시 데이터로 체험" 버튼으로 합성 데이터를 먼저 볼 수 있습니다.

## 올릴 수 있는 파일

| 파일 | 필수 | NEIS 메뉴 | 역할 |
|---|---|---|---|
| 교과목별 학생답 정오표 (반별) | **필수** | 성적 › 지필평가조회 › 교과목별 학생답 정오표 조회 › 저장 | 학생 응답·점수. 정답·배점도 여기서 읽음 |
| 문항정보표 (성취기준·난이도 포함) | 선택 | 성적 › 지필평가 › 문항정보표 › 출력 › XLS data | 성취기준·내용영역·예상난이도 분석 |
| 정답/배점표 (간략형 문항정보표) | 선택 | 성적 › 지필평가조회 › 정답/배점 | 정오표와 대조 검증, 복수정답 |
| 문항분석표 | 선택 | 성적 › 지필평가조회 › 문항분석표 | 담당 반만 올렸을 때 "학년 전체" 비교 |

- 파일 종류는 내용을 보고 자동으로 판별하므로 파일명은 아무래도 좋습니다. 여러 반 파일을 한꺼번에 올리세요.
- 정오표만 있어도 성취도·문항·성취수준별·학생별 분석이 모두 됩니다. 문항정보표(성취기준 포함)를 함께 올리면 성취기준·내용영역 탭이 추가됩니다.
- 문항분석표는 입력이 아니라 **산출물**이기도 합니다. 정오표만으로 NEIS 양식의 문항분석표를 반별로 다시 만들어 보여 주고 엑셀로 내보냅니다. 모든 반을 올리면 괄호 안 "학년 전체" 수치까지 자동으로 채워집니다.
- 서답형은 NEIS 정오표에 총점만 있으므로 총점으로 분석합니다. 문항별 분석을 원하면 정오표의 마지막 선다형 문항과 "선택형점수" 열 사이에 `서답1, 서답2 …` 열을 추가하고 배점 행과 학생별 점수를 채워 올리세요.

## 분석 내용

| 탭 | 내용 |
|---|---|
| 개요 | 응답자·문항 수, 평균·표준편차, 신뢰도 α, 성취수준 분포(학급별 누적막대), 점수 히스토그램(성취수준 색·분할점수 선), 성취수준별 평균·표준편차 |
| 학급별 | 학급별 성취도 표, 문항×학급 정답률 열지도(+학년 전체 열), **NEIS 양식 문항분석표 재구성** |
| 문항 분석 | 정답률, 난이도 판정, 변별도(해석 배지), 답지반응률(정답 답지 강조), 예상난이도와 비교, 확인 필요 플래그 → 행 클릭 시 성취수준별·학급별 상세 |
| 성취수준별 | 수준별 정답률 상·하위 3문항, 문항×성취수준 정답률 행렬(수준 역전 표시), 수준별 답지반응률 |
| 성취기준·영역 | 성취기준별·내용영역별 성취율(전체·수준별·학급별), 보완이 필요한 성취기준 |
| 서답형 | 성취수준별 서답형 총점, (문항별 열이 있으면) 문항별 평균·점수 분포 |
| 학생별 | 명부(검색·정렬) → 개인별 리포트: 성취수준, 틀린 문항(내 답·정답·전체 정답률), 성취기준별 도달 현황 |

추가 기능: 분할점수·산출 기준·표준편차 방식 설정, 학급 필터, **엑셀 내보내기**(11개 시트, 기존 KICE 프로그램 출력 구성), **A4 인쇄 보고서**(PDF 저장), **학생 개인별 리포트 인쇄**(반 전체 일괄).

## 계산 방식 (기존 KICE "성취수준별 평가결과 분석 프로그램"과 동일한 값이 나오도록 검증)

- 성취수준: 총점 ÷ 과목 만점 × 100 이 분할점수(기본 90/80/70/60) **이상**이면 해당 수준. 선다형 만점 기준으로 바꿀 수 있습니다.
- 표준편차: 기본 모집단(÷N, KICE 프로그램과 동일). 설정에서 표본(÷(N−1))으로 변경 가능.
- 정답률·답지반응률: 분모는 집단 전체(무응답 포함). 무표기·복수표기·무효는 "무응답/중복" 한 칸. 문항분석표 재구성 표만 NEIS 방식(복수표기를 표기한 답지마다 세고 중복표기 열에도 셈)을 따릅니다.
- 변별도: 문항 획득 점수와 (총점 − 문항 점수)의 피어슨 상관(수정 문항-총점 상관), 총점 = 선다형 + 서답형.
- 신뢰도: 선다형 0/1 KR-20(Cronbach α). 서답형 문항별 점수가 있으면 배점 가중 α도 함께 표시.
- 성취기준 성취율: 해당 성취기준 문항의 획득 점수 합 ÷ 배점 합 × 100.
- 해석 기준(교육부·KICE): 난이도 75%/25%, 변별도 .10/.20/.30/.40, 신뢰도 .50~.90(Knapp).

## 개발

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest
npm run build      # dist/
npm run make-demo  # public/demo/ 합성 데모 파일 재생성
```

실제 NEIS 샘플이나 KICE 샘플로 검증하려면 경로를 환경변수로 지정합니다 (샘플은 저장소에 포함하지 않습니다).

```powershell
$env:NEIS_SAMPLE_DIR = "C:\경로\성취평가"                        # 분석할 자료* 하위 폴더를 가진 상위 폴더
$env:KICE_SAMPLE_XLS = "C:\경로\SAMPLE\과목C 학생답정오표(서답형).xls"
npm test -- --run
```

`main` 브랜치에 푸시하면 GitHub Actions가 테스트·빌드 후 GitHub Pages에 배포합니다.
